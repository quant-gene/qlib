# 基准测试性能

本页面列出了一系列用于寻找alpha的方法。每种方法都会尝试每天对所有股票给出分数/预测（例如预测股票未来超额收益）。模型的分数/预测将被用作挖掘出的alpha。投资于分数较高的股票预期会获得更多的利润。

alpha通过两种方式进行评估：
1. alpha与未来收益的相关性。
2. 基于alpha构建投资组合并评估最终总收益。
   - 指标解释可参考[此处](https://qlib.readthedocs.io/en/latest/component/report.html#id4)

以下是在Qlib的`Alpha360`和`Alpha158`数据集上运行各基准模型的结果，使用的数据分别为中国A股和沪深300数据。每个指标的值都是基于20次不同随机种子运行计算得出的均值和标准差。

下面显示的数字展示了每个模型整个`工作流程`的性能。我们将在不久的将来更新`工作流程`以及模型以获得更好的结果。

# 贡献

非常欢迎您对新模型的贡献！

如果您想贡献新模型，可以遵循以下步骤。
1. 为您的模型创建一个文件夹
2. 文件夹包含以下项目（您可以参考[这个示例](https://github.com/microsoft/qlib/tree/main/examples/benchmarks/TCTS)）。
    - `requirements.txt`：所需的依赖包。
    - `README.md`：对您的模型的简要介绍
    - `workflow_config_<model name>_<dataset>.yaml`：可以被`qrun`读取的配置文件。建议您在所有数据集上运行您的模型。
3. 您可以将您的模型作为模块集成到[此文件夹](https://github.com/microsoft/qlib/tree/main/qlib/contrib/model)中。
4. 请在上述**基准测试表**中更新您的结果，例如[Alpha360](#alpha158-dataset)，[Alpha158](#alpha158-dataset)（每个指标的值是基于**20次运行**不同随机种子的均值和标准差计算得出的。您可以通过Qlib提供的自动化[脚本](https://github.com/microsoft/qlib/blob/main/examples/run_all_model.py)完成上述操作，并在.md文件中获得最终结果。如果您的计算资源不够，可以在PR中请求帮助）。
5. 更新索引页面中的信息，在[新闻列表](https://github.com/microsoft/qlib#newspaper-whats-new----sparkling_heart)和[模型列表](https://github.com/microsoft/qlib#quant-model-paper-zoo)中。

最后，您可以发送PR等待审查。([这里有一个示例](https://github.com/microsoft/qlib/pull/1040))


# 常见问题

问：名称为`*.py`和`*_ts.py`的模型有什么区别？

答：名称为`*_ts.py`的模型是为`TSDatasetH`设计的(`TSDatasetH`会自动从表格数据生成时间序列)。名称为`*.py`的模型是为`DatasetH`设计的(`DatasetH`通常用于表格数据。但如果列之间有时间序列关系，用户仍可以在表格数据集上应用时间序列模型)。
